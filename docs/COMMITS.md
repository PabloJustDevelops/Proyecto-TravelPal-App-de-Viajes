# Commits Semánticos

Formato: `tipo(scope): descripción breve`

Tipos comunes:
- `feat`: nueva funcionalidad
- `fix`: corrección de bug
- `docs`: cambios en documentación
- `chore`: tareas varias (build, deps)
- `refactor`: reestructuración sin cambiar comportamiento
- `test`: pruebas
- `style`: formato/estilo

Ejemplos:
- `feat(analytics): filtrar por moneda y rango`
- `fix(budget): corregir cálculo de porcentajes`

Reglas:
- Máx ~72 caracteres en descripción.
- Usar imperativo y español neutro.
- Añadir cuerpo si aplica (qué/por qué).
