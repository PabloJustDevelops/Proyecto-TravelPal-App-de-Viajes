# Guía de Contribución

## Requisitos
- Leer `README.md` y `docs/TECHNICAL.md`.
- Configurar `.env.local`.

## Flujo de trabajo
- Crear rama desde `main`: `feature/`, `fix/`, `chore/`.
- Commits semánticos (ver `docs/COMMITS.md`).
- Abrir PR hacia `main` siguiendo la plantilla.
- Solicitar review y cumplir checklist.

## Estándares
- Lint sin errores: `npm run lint`.
- Tests pasan: `npm test`.
- Mantener estilo de código y convenciones.

## Comunicación
- Usar issues para discutir features/bugs.
- Etiquetar como `bug`, `feature`, `enhancement`.
